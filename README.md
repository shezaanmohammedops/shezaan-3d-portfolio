# Mohammed Shezaan — 3D Portfolio

Premium responsive developer portfolio with an interactive CSS 3D hero, smooth sections, project cards, skills, education and contact links.

## Run

```powershell
npm install
npm run dev
```

Open the localhost URL shown by Vite (normally http://localhost:5173/).

## Build check

```powershell
npm run build
```

The project intentionally keeps dependencies minimal to avoid 3D/WebGL runtime failures and black-screen issues.
